## ✈️ Aviation Examples

I used lambda functions to calculate ticket fares, classify ticket prices, and demonstrate flight delay status.

## 📖 Example

```python
calculate_fare = lambda price, passengers: price * passengers

print(calculate_fare(500, 3))
```

Output:

```text
1500
```

## 🔑 Key Learning

A lambda function is a concise function written with the `lambda` keyword. It contains a single expression and returns that expression's result.
