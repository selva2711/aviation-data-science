# Day 4 – Python Comparison Operators

## 📚 What I Learned

Today I learned about Python comparison operators.

Comparison operators are used to compare two values. The result of a comparison is either `True` or `False`.

## 🔹 Comparison Operators

| Operator | Meaning | Example |
|---|---|---|
| `>` | Greater than | `250 > 200` |
| `<` | Less than | `150 < 200` |
| `==` | Equal to | `250 == 250` |
| `!=` | Not equal to | `250 != 200` |
| `>=` | Greater than or equal to | `250 >= 250` |
| `<=` | Less than or equal to | `50 <= 50` |

## 1. Greater Than (`>`)

Checks whether the first value is greater than the second value.

## python
passengers = 250
print(passengers > 200)

## Output
True

## 2. Less Than (<)

Checks whether the first value is smaller than the second value.

passengers = 150
print(passengers < 200)

## Output
True

## 3. Equal To (==)

Checks whether two values are equal.

passengers = 250
print(passengers == 250)

## Output
True

## 4. Not Equal (!=)

Checks whether two values are different.

destination = "Chennai"
print(destination != "Doha")

## Output
True

## 5. Greater Than or Equal To (>=)

Checks whether a value is greater than or equal to another value.

passengers = 250
print(passengers >= 250)

## Output
True

6. Less Than or Equal To (<=)

Checks whether a value is less than or equal to another value.

available_seats = 50
print(available_seats <= 50)

## Output
True

## 🎯 Key Takeaways
Comparison operators compare values.
The result is True or False.
> means greater than.
< means less than.
== means equal to.
!= means not equal to.
>= means greater than or equal to.
