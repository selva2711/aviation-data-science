# Day 1 – Python Variables

## 📚 What I Learned

Today I learned the basics of Python Variables.

### 🔹 What is a Variable?

A variable is a name used to store a value.

### Example:
python
airline = "Qatar Airways"
passengers = 200

### 🔹 Text Values

Text is written inside quotation marks.

airline = "Qatar Airways"
destination = "Mumbai"

### 🔹 Number Values

Numbers do not need quotation marks.

passengers = 200

### 🔹 print()

The print() function displays a value.

print(airline)
print(passengers)

### 🔹 Variable Naming

I learned to use clear variable names with snake_case.

Example:

flight_number = "QR170"
passenger_count = 200

### ✈️ Aviation Example

airline = "Qatar Airways"
flight_number = "QR170"
origin = "Doha"
destination = "Mumbai"
passengers = 200

print(airline)
print(flight_number)
print(origin)
print(destination)
print(passengers)

### 🎯 Key Takeaways

A variable stores a value.
Text values use quotation marks.
Numbers do not need quotation marks.
print() displays information.
Clear variable names make code easier to understand.
Python variables are an important foundation for Data Science.
