
# Day 44: Python sum() Function

## Overview
Learned how to use Python's built-in sum() function to calculate the total of numeric values in a list.

## 🧠 Topics Covered
- Introduction to sum()
- sum() with lists
- Calculating total values
- Using sum() with for loops
- Using append() to collect values
- Working with aviation flight records

## ✈️ Aviation Examples
- Calculating total passengers across flights
- Calculating total ticket revenue
- Calculating total flight delays
- Collecting passenger counts from multiple flight records

## 📖 Example

```python
passengers = [180, 250, 320]

total_passengers = sum(passengers)

print("Passenger Counts:", passengers)
print("Total Passengers:", total_passengers)
```

## Output

```text
Passenger Counts: [180, 250, 320]
Total Passengers: 750
```

## 🔑 Key Learning
- sum() calculates the total of numeric values.
- sum() works with lists of numbers.
- for loops can collect values from flight records.
- append() adds values to a list.
- sum() can calculate total passengers, revenue, and delays.
