## ✈️ Aviation Examples
- Sorting flight delays
- Sorting passenger counts
- Sorting flight numbers
- Arranging flight delays from highest to lowest
- Sorting delay values collected from flight records

## 📖 Example

```python
flight_delays = [45, 15, 30, 10, 25]

sorted_delays = sorted(flight_delays)

print("Original Flight Delays:", flight_delays)
print("Sorted Flight Delays:", sorted_delays)
```

## Output

```text
Original Flight Delays: [45, 15, 30, 10, 25]
Sorted Flight Delays: [10, 15, 25, 30, 45]
```

## 🔑 Key Learning
- sorted() arranges values in ascending order by default.
- sorted() works with numbers and strings.
- reverse=True arranges values in descending order.
- sorted() returns a new sorted list.
- The original list remains unchanged.
