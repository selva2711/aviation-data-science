# Day 2 – Python Data Types

## 📚 What I Learned

Today I learned about the four basic Python data types commonly used in Data Science.

## 1. String (`str`)

A String stores text values.

python
airline = "Qatar Airways"
destination = "Doha"

## 2. Integer (int)

An Integer stores whole numbers without decimal points.

passengers = 250
flight_count = 15

## 3. Float (float)

A Float stores numbers with decimal values.

ticket_price = 525.50
flight_hours = 6.5

## 4. Boolean (bool)

A Boolean stores one of two values:

True
False

Example:

flight_delayed = False

## 🔍 Checking Data Types

Python provides the type() function to identify the data type of a value.

print(type(airline))
print(type(passengers))
print(type(ticket_price))
print(type(flight_delayed))

## ✈️ Aviation Data Science Example

airline = "Qatar Airways"
passengers = 250
ticket_price = 525.50
flight_delayed = False

print("Airline:", airline)
print("Passengers:", passengers)
print("Ticket Price:", ticket_price)
print("Flight Delayed:", flight_delayed)

| Data Type | Meaning        | Example  |
| --------- | -------------- | -------- |
| `str`     | Text           | `"Doha"` |
| `int`     | Whole number   | `250`    |
| `float`   | Decimal number | `525.50` |
| `bool`    | True or False  | `False`  |

## 🎯 Key Takeaways
str is used for text.
int is used for whole numbers.
float is used for decimal numbers.
bool is used for True or False values.
type() is used to check the data type.
Understanding data types is an important foundation for Data Science.
