
# Day 45: Python len() Function

## Overview
Learned how to use Python's built-in len() function to count the number of items in a collection and characters in a string.

## 🧠 Topics Covered
- Introduction to len()
- len() with Lists
- len() with Strings
- Counting Passenger Names
- Counting Flight Numbers

- Using append() to collect flight numbers

## ✈️ Aviation Examples
- Counting total passengers
- Counting airline flight numbers
- Counting characters in a flight number
- Counting flights using flight records

## 📖 Example

```python
passengers = ["Arun", "Priya", "David", "Sara", "John"]

total_passengers = len(passengers)

print("Passenger List:", passengers)
print("Total Passengers:", total_passengers)
```

## Output

```text
Passenger List: ['Arun', 'Priya', 'David', 'Sara', 'John']
Total Passengers: 5
```

## 🔑 Key Learning
- len() counts the number of items in a list.
- len() counts the characters in a string.
- len() can count flight numbers and passenger names.
- for loops can collect flight numbers from flight records.
- append() adds values to a list.
