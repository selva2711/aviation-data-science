## 🔹 Arithmetic Operators

Python provides arithmetic operators for mathematical calculations.

| Operator | Meaning | Example |
|---|---|---|
| `+` | Addition | `120 + 80` |
| `-` | Subtraction | `300 - 250` |
| `*` | Multiplication | `500 * 4` |
| `/` | Division | `600 / 2` |
| `%` | Remainder | `203 % 4` |

## 1. Addition (`+`)

The `+` operator is used to add values.

## python
total_passengers = passengers_doha + passengers_mumbai

Example:

120 + 80 = 200

## 2. Subtraction (-)

The - operator is used to subtract one value from another.

available_seats = total_seats - booked_seats

Example:

300 - 250 = 50

## 3. Multiplication (*)

The * operator is used to multiply values.

total_revenue = ticket_price * passengers

Example:

500 × 4 = 2000

## 4. Division (/)

The / operator is used to divide values.

average_speed = total_distance / flight_hours

Example:

600 / 2 = 300.0

## 5. Remainder (%)

The % operator returns the remainder after division.

Example:

remaining_passengers = 203 % 4

203 ÷ 4 leaves a remainder of 3.

Therefore:

203 % 4 = 3

## ✈️ Aviation Example

passengers_doha = 120
passengers_mumbai = 80

total_passengers = passengers_doha + passengers_mumbai
print("Total Passengers:", total_passengers)

total_seats = 300
booked_seats = 250

available_seats = total_seats - booked_seats
print("Available Seats:", available_seats)

ticket_price = 500
passengers = 4

total_revenue = ticket_price * passengers
print("Total Revenue:", total_revenue)

## 🎯 Key Takeaways
+ is used for addition.
- is used for subtraction.
* is used for multiplication.
/ is used for division.
% is used to find the remainder.
Python operators are useful for calculations in Data Science.
Operators can be used to analyze real-world aviation data.
